Welcome! This is the first post on my new blog. Here I'll share practical, hands-on guides about **Azure**, **Kubernetes**, **DevOps**, **Infrastructure as Code** and **AI**.

## What to expect

- Step-by-step tutorials from real-world projects
- Notes from my certification journey (CKA, Azure certs)
- Tips on Terraform, Bicep and GitHub Actions

## How this site is built

This site is built with [Astro](https://astro.build) and deployed to GitHub Pages using GitHub Actions. Every post is a Markdown file in `src/content/blog/`.

```bash
npm install
npm run dev
```

> Writing a new post is as simple as adding a new `.md` file and pushing to `main`.

Thanks for stopping by!
